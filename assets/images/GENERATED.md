# Demo imagery

All people and lifestyle images in this folder were generated locally with
**OpenMOSS-Team / MOSS-Image-Base** using the user's existing local weights at
`C:\Users\hu\AI\MOSS-Image`.

- Model license: Apache License 2.0
- Generation: 16 inference steps, guidance scale 3.0
- Portraits: 960 × 1280, final JPEG quality 90
- The people are wholly synthetic; they do not depict real members.
- No model weights are stored in this repository and no model was downloaded
  while producing the site.
